# ig-publisher

Configures, runs and debugs the HL7 FHIR IG Publisher for an Implementation Guide, including ig.ini, IG parameters (path-binary, path-resource, path-liquid…), which input folders come from the template and which from the IG, the CQL loader and ig-loader Libraries, command-line flags, terminology servers and pinning, qa.html and ignoreWarnings.txt. Use when someone builds a FHIR IG, asks why the publisher did something, or reads a QA report. Pinned to IG Publisher 3.0.4, hl7.fhir.uv.tools 1.3.0 and cqf.fhir.template 1.0.0.
