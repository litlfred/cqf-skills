# usqualitycore

Looks up and applies US Quality Core 0.5.0 (fhir.onc.us-quality-core), the ONC profiles for USCDI+ Quality built on US Core 6.1.0 and derived from QI-Core 6.0.0. Covers USCDI+ Quality flags, in-scope profiles and conformance, negation profiles, the QDM-to-US Quality Core mapping, the USQualityCore ModelInfo and USQualityCoreCommon. Use when building or checking data against US Quality Core, choosing a US Quality Core profile, or writing CQL with `using USQualityCore`. For CMS measure authoring patterns, use the cms-qmd skill.
