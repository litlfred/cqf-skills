# terminology

Works with terminology for CQL and FHIR knowledge artifacts — CQL codesystem, valueset and code declarations and the in, ~ and = operators on codes; FHIR R4 ValueSet and CodeSystem resources; the $expand, $validate-code, $lookup, $subsumes and ConceptMap $translate operations; pinning value set and code system versions for reproducible evaluation (expansion parameters, CRMI manifests); and putting expanded value sets where local CQL tooling and test runs find them. Use when a retrieve finds nothing because of a code or value set, when a value set must be expanded or pinned, when choosing between a direct-reference code and a value set, or when wiring a terminology server. Not for authoring the CQL logic (cql), IG Publisher terminology settings (ig-publisher) or FSH syntax for ValueSets (fsh).
