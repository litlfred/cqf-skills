# us-cql-ig

Writes CQL against US Core using the Common CQL Artifacts for FHIR (US-Based) IG (hl7.fhir.us.cql 2.0.0), which publishes the USCore ModelInfo (6.1.0-derived) and the USCoreCommon, USCoreElements, QICoreCommon and CumulativeMedicationDuration libraries. Covers retrieving US Core profiles, primary code paths, modifier and status handling, and the patient, condition, observation, medication and service patterns. Use when CQL uses USCore, includes USCoreCommon or USCoreElements, or asks how to express US Core data in CQL.
