# cql-ig

Applies the Using CQL With FHIR IG (hl7.fhir.uv.cql 2.0.0), which publishes the FHIR ModelInfo, FHIRHelpers and FHIRCommon. Covers its conformance rules for CQL written against FHIR, packaging CQL as a FHIR Library (CQLLibrary and ELM profiles, relatedArtifact, parameters, dataRequirement), the CQL-to-FHIR type mapping, $cql and Library/$evaluate, and FHIR authoring patterns (primitives, choices, extensions, missing data, negation). Use when CQL uses FHIR, a FHIR Library carries CQL, or someone asks what FHIRHelpers, FHIRCommon or the FHIR ModelInfo provide.
