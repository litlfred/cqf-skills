# measure Skill Trigger Prompts

## Should load the skill

1. My proportion measure counts a patient in the numerator who also has a denominator exception. Is that right?
2. Write the group and population elements of a FHIR Measure for an Encounter-based measure.
3. What reportType do I pass to Measure/$evaluate-measure to get one report per patient list?
4. The MeasureReport shows measureScore 0.5 but I expected 0.6; how is the score computed?
5. Add a stratifier by age group to this Measure.

## Should not load the skill

1. Write the CQL for "Encounter during the Measurement Period".
2. Import these test cases into MADiE.
3. Package this Measure and its libraries with $package.
4. Expand this value set with $expand.

Prompt 1 belongs to `cql`, 2 to `madie`, 3 to `crmi`, 4 to `terminology`.
