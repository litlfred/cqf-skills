# immunization-cds evals

Evals for the `immunization-cds` skill (litlfred fork). `triggers.md` checks when the skill loads;
`questions.md` is given to the agent under test, `answers.md` is the key and is not. Run each with and
without the skill installed and compare. The answers are the behaviour recorded in the skill's probe
(`skills/immunization-cds/resources/probes/2026-11-17/RESULTS.md`).
